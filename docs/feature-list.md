## 📝️ 기능 목록

### ▪️ 입력 기능

- [] 사용자 이름 입력받기
    - [] 공백일 경우 예외를 발생시키기

- [] 손패 중, 낼 카드 입력하기
    - [] 현재 합계 보여주기
    - [] 현재 손패 보여주기
    - [] 공백일 경우 예외를 발생시키기

### ▪️ 보조 기능

- [] 잘못된 값이 들어올 시 출력 후 재입력 받기
- [] 정수형으로 파싱하기
    - [] 정수가 아닌 경우 예외를 반환한다.

### ▪️ 비지니스 기능

- 덱을 초기화한다.
    - [] 게임 시작 시, 모든 카드를 덱에 등록한다.

- 사용자를 등록한다.
    - [] 봇을 등록한다.
    - [] 유저를 등록한다.
    - 조건 미충족 시 예외를 반환한다.
        - [] 이름은 `최소 2자, 최대 10자`여야 한다.
        - [] 이름 형식은 소문자 영문, 숫자만 허용한다.

- 참여자에게 카드를 부여한다.
    - [] 시스템에 등록된 카드 중 5장을 랜덤으로 게임 참여자에게 부여한다.

- 게임 종료 조건에 도달할 때까지 아래 단계를 반복한다.
    - 순서를 확인한다.
        - [] 현재 순서에 카드를 제출할 플레이어를 찾는다.
        - [] 다음 플레이어로 순서을 넘긴다.

    - 카드를 테이블에 제출한다.
        - [] 제출한 카드를 손패에서 제거한다.
        - [] 손패에서 제거한 카드 수만큼, 새 카드를 손패에 추가한다.
        - [] 손패에서 제거한 카드 수만큼, 랜덤으로 덱에 있는 카드를 제거한다.
        - 조건 미충족 시 예외를 반환한다.
            - [] 손패에 있는 카드만 제출할 수 있다.

    - 제출한 카드의 효과를 적용한다.
        - [] 특수카드인지 판단한다.
        - [] 자신의 기능을 수행한다.

    - 우승자를 판단한다.
        - [] 상대가 카드를 제출한 후, 합계가 `77`을 초과한 경우
        - [] 상대가 카드를 제출한 후, 합계가 `11의 배수`인 경우

### ▪️ 출력 기능

- 카드 제출 결과 출력
    - [] 카드 사용 내역 출력
    - [] 현재 합계 출력
- [] 우승자 출력
- [] 예외 메세지 출력
    - `[ERROR]` 로 시작할 것
